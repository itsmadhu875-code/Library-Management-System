# 📚 Library Management System in C++

## About the Project
The Library Management System is a console-based application developed using C++. It helps users manage library books efficiently.

## Features
- Add new books
- Display all books
- Search books by ID
- Issue books
- Return books
- Store book records using file handling

## Technologies Used
- C++
- File Handling
- Object-Oriented Programming Basics

## How to Run
1. Download or clone this repository.
2. Open the project in a C++ editor.
3. Compile the source code using a C++ compiler.

```bash
g++ "library management system.cpp" -o library
```

4. Run the program.

On Windows:
```bash
library.exe
```
